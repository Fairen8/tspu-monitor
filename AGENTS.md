* НИКОГДА не выполнять `gh pr merge` (и любые другие действия, приводящие
  к слиянию PR, например `git merge` + push в `release`) без явного

* Если пользователь дал добро на конкретный PR — это не разрешение на
  последующие мерджи: каждый PR подтверждается отдельно.
